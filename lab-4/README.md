## Опис завдання:
* Частина 1: Робота у віртуальному середовищі,використання бібліотек,обробка даних:
    
    -Встановлення бібліотек numpy, matplotlib, scipy
    
    -Генерація часової шкали тривалістю 8 секунд із частотою дискретизації 800 Гц

    -Генерація базового шуму як основного масиву даних

    -Очищення даних через контроль параметрів генерації (обмеження діапазонів амплітуди, частоти, дисперсії шуму)
* Частина 2: Аналіз даних гармонічного сигналу
    
    -Реалізація функції get_clean_harmonic – генерація чистого сигналу y = A·sin(ωt + φ)
    
    -Реалізація функції get_current_noise – накладання гаусового шуму із заданими середнім та дисперсією
    
    -Створення інтерактивного інтерфейсу: слайдери для амплітуди (0.2-3.5), частоти (0.3-12 Гц), фази (0-2π), середнього шуму (-0.8-0.8), дисперсії шуму (0-0.8), частоти зрізу фільтра (5-60 Гц),чекбокс для ввімкнення/вимкнення відображення шуму,кнопка «Reset» для відновлення початкових параметрів
    
    -Фільтрація зашумленого сигналу – використання фільтра Баттерворта 4-го порядку (scipy.signal.butter) з нульово-фазовою фільтрацією (scipy.signal.filtfilt)
    
    -Забезпечення незалежності шуму – базовий шум генерується один раз на початку програми. При зміні параметрів гармоніки шум залишається незмінним, при зміні параметрів шуму – масштабується відповідно до нових значень
* Лінії на графіку
    
    -Зелена лінія (суцільна) – чиста гармоніка y(t) = A·sin(ωt + φ) без шуму
    
    -Помаранчева лінія (суцільна, напівпрозора) – зашумлений сигнал (чиста гармоніка + накладений гаусів шум)
    
    -Фіолетова лінія (пунктирна) – відфільтрований сигнал (результат застосування фільтра Баттерворта до зашумленого сигналу)
