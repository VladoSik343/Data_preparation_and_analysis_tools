## Опис завдання:
У ході виконання роботи розглядається ключова робота з реальними даними за допомогою використання інструментів Python
* Частина 1:робота у віртуальному середовищі,використання `urllib` для завантаження файлів,обробка даних(`Data Cleaning`),виконання вибірок за допомогою pandas.
* Частина 2:аналіз даних споживання електроенергії,очищення даних,створення вибірок за різними умовами,статистичний аналіз, обчислення кореляцій,нормалізація,стандартизація та кодування категоріальних ознак.
## Вимоги до системи:
* Операційна система: `Windows`/`Linux`/`macOS`
* Інтерпретатор: `Python 3.9+`
* Необхідні бібліотеки:  `pandas`, `numpy`, `scikit-learn`, `jupyter` тощо(можна подивитись у разі необхідності у requirements.txt )
## Інструкція із запуску:
1. Відкрити термінал у теці `lab-2`
2. Створити `python -m venv venv` та активувати віртуальне середовище `venv\Scripts\activate`
3. Встановити усі необхідні залежності: `pip install -r requirements.txt`
4. При виконанні 2 частини необхідно завантажити файл `household_power_consumption.txt` з репозиторію UCI та покласти у теку lab-2
5. Запустити Jupyter Notebook в терміналі: `jupyter notebook`
6. Відкрити файли part_1.ipynb та part_2.ipynb і необхідно послідовно виконати кожну комірку.
