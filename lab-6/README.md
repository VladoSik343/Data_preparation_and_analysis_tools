# Лабораторна робота №6

C++ openCV

## Опис завдання:
В рамках даної лабораторної роботи створено інтерактивний C++ додаток для обробки відео з камери в реальному часі з використанням бібліотеки OpenCV.
## Функціонал додатку:

- **Захоплення відео з камери** з регульованою роздільною здатністю
- **Багато режимів обробки зображень:**
  - Нормальний режим з регулюванням яскравості
  - Інверсія кольорів
  - Розмиття за Гауссом
  - Canny виявлення меж
  - Фільтр Собеля
  - Бінарна порогова обробка
  - Glitch ефект (зсув RGB каналів)
  - Режим малювання (малюйте на відео мишею)
  - Режим зума (керуйте зумом колесом миші)
  - Режим обертання

- **Інтерактивне керування:**
  - Гарячі клавіші для перемикання режимів
  - Малювання мишею
  - Зум колесом миші
  - Повзунки для регулювання параметрів (яскравість, розмиття, пороги)

- **Інформація на екрані:**
  - Поточний режим обробки
  - Лічильник FPS в реальному часі
  - Підказки з керування

## Вимоги до системи

### Операційна система
- Ubuntu 20.04 або новіші версії (або будь-який Debian-подібний дистрибутив Linux)
- Інші дистрибутиви Linux можуть працювати з коригуванням менеджера пакетів

### Апаратне забезпечення
- Веб-камера або вбудована камера
- Мінімум 2 ГБ оперативної пам'яті
- Процесор: будь-який сучасний процесор (рекомендується 2+ ядра)

### Програмне забезпечення
- OpenCV 4.x
- CMake 3.10+
- GCC/G++ 7+ з підтримкою C++17
- Make

## Встановлення та запуск

### Швидке встановлення

```bash
1. Клонуйте репозиторій:
git clone <https://github.com/VladoSik343/Data_preparation_and_analysis_tools.git>
cd lab-6
2. Надайте права на виконання скриптам:
chmod +x preinstall.sh build.sh run.sh
3.Перетворити формат рядків(помилка виникає через те, що файл має неправильний формат рядків):
sed -i 's/\r$//' preinstall.sh build.sh run.sh
4.Запустіть скрипт попереднього встановлення (встановлює всі залежності):
./preinstall.sh
5.Зберіть додаток:
./build.sh
6.Запустіть додаток:
./run.sh
