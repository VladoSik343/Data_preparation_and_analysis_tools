## Опис завдання:
У ході виконання роботи здійснюється повний цикл аналізу датасету Heart Disease з використанням інструментів Python.
* Частина 1: Data Cleaning - завантаження даних з UCI Repository. Створення бінарної цільової змінної has_disease (0 – здоровий, 1 – хворий).Візуалізація залежностей - побудова графіків для аналізу зв'язків між числовими атрибутами, гістограми розподілу віку з розбиттям на групи, стовпчикові діаграми розподілу хвороби за статтю.
## Вимоги до системи:
* Операційна система: `Windows`/`Linux`/`macOS`
* Інтерпретатор: `Python 3.9+`
* Необхідні бібліотеки:  `pandas`, `numpy`, `scikit-learn`, `jupyter` тощо(можна подивитись у разі необхідності у requirements.txt )
## Інструкція із запуску:
1. Відкрити термінал у теці `lab-2`
2. Створити `python -m venv venv` та активувати віртуальне середовище `venv\Scripts\activate`
3. Встановити усі необхідні залежності: `pip install -r requirements.txt`
4. Запустити Jupyter Notebook в терміналі: `jupyter notebook`
5. Відкрити файл lab-3.ipynb та послідовно виконати кожну комірку.
