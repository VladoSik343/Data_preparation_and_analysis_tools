# Наука про дані: обмін результатами та початковий аналіз
## Опис завдання:
В рамках лабораторної роботи створено інтерактивний веб-додаток для аналізу часових рядів вегетаційних індексів VCI (Vegetation Condition Index), TCI (Temperature Condition Index) та VHI (Vegetation Health Index) для 27 областей України за період 1982-2024 років.
## Функціонал додатку

**Фільтрація даних:**
- Вибір області України з випадаючого списку (27 областей)
- Вибір часового ряду для аналізу: VCI, TCI або VHI
- Вибір інтервалу тижнів (від 1 до 52) за допомогою повзунка
- Вибір інтервалу років (від 1982 до 2024) за допомогою повзунка
- Кнопка скидання всіх фільтрів до початкових значень

**Сортування даних:**
- Чекбокс для сортування таблиці за зростанням значень
- Чекбокс для сортування таблиці за спаданням значень
- При активації обох чекбоксів одночасно сортування вимикається з відповідним повідомленням

## Візуалізація

**Таблиця даних:**
Відображає відфільтровані дані у вигляді трьох колонок: рік, тиждень та значення обраного часового ряду. Кількість записів динамічно змінюється відповідно до обраних фільтрів.

**Графік динаміки обраної області:**
Лінійна діаграма синього кольору, де вісь X відображає час у форматі дати, а вісь Y - значення обраного індексу (VCI, TCI або VHI). Графік дозволяє візуально оцінити сезонні коливання та довгострокові тренди. Над графіком відображаються метрики: мінімальне, максимальне та середнє значення за обраний період.

**Діаграма порівняння областей:**
Стовпчикова діаграма, яка показує середні значення обраного індексу для всіх областей. Обрана користувачем область виділяється червоним кольором, інші області - синім. Діаграма дозволяє швидко порівняти стан рослинності в різних регіонах України.
