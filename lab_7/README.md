# Лабораторна робота №7

Computer Vision та багатопотоковість у C++

## Опис завдання:
Створення інтерактивного C++ додатку для обробки відео з камери в реальному часі з використанням бібліотеки OpenCV та багатопотокової детекції облич.
## Функціонал додатку:

- **Захоплення відео з камери** з регульованою роздільною здатністю
- **Багато режимів обробки зображень:**
  - Нормальний режим з регулюванням яскравості
  - Інверсія кольорів
  - Розмиття за Гауссом
  - Canny виявлення меж
  - Фільтр Собеля
  - Бінарна порогова обробка
  - Glitch ефект (зсув RGB каналів)
  - Режим малювання (малюйте на відео мишею)
  - Режим зума (керуйте зумом колесом миші)
  - Режим обертання
  - Детекція облич (Виявлення облич за допомогою нейронної мережі)

- #### Інтерактивне керування:

- **Гарячі клавіші** для перемикання режимів
- **Малювання мишею** (ЛКМ + перетягування в режимі 'd')
- **Зум колесом миші** (в режимі 'z')
- **Повзунки (Trackbars)** для регулювання параметрів:
  - Яскравість (Brightness)
  - Розмір ядра розмиття (Blur Size)
  - Поріг для Canny детектора (Canny Threshold)
  - Поріг бінаризації (Binary Threshold)

#### Інформація на екрані:

- Поточний режим обробки
- Лічильник FPS в реальному часі
- Підказки з керування
- Кількість виявлених облич (в режимі детекції)

### Додаткова функціональність: Детекція облич з використанням нейронних мереж

#### Рівень 1: Базова детекція облич

Програма підтримує режим детекції облич за допомогою нейронної мережі ResNet-10 SSD.

**Особливості:**
- Використовує попередньо навчену модель Caffe (ResNet-10 SSD)
- Розмір вхідного зображення: 300x300 пікселів
- Поріг впевненості: 50%
- Малює зелені прямокутники навколо виявлених облич
- Відображає відсоток впевненості детекції

#### Рівень 2: Багатопотокова детекція облич

**Проблема:** Інференс нейромережі може займати 50-100 мс, що викликає "смикання" відео при 30 FPS (інтервал між кадрами ~33 мс).

**Рішення:** Винесення детекції в окремий потік.

##### Клас FaceDetector

**Методи:**
- `loadModel()` - завантаження нейронної мережі
- `start()` - запуск робочого потоку
- `stop()` - зупинка потоку
- `updateFrame()` - відправка кадру в потік (з м'ютексом)
- `getFaces()` - отримання результатів детекції (з м'ютексом)

**Синхронізація:**
- `std::mutex` - захист спільних даних (координати облич)
- `std::mutex` - захист кадру, що обробляється
- `std::condition_variable` - сигналізація про новий кадр
- `std::atomic<bool>` - безпечне керування станом потоку

- CMake 3.10+
- GCC/G++ 7+ з підтримкою C++17

- wget (для завантаження моделі нейронної мережі)
